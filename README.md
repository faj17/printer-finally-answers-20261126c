Entry for the make.fun competition
[The Printer Finally Answers](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907):
one line, 1 to 240 characters, as the office printer's comeback to everyone
staring at it — the paper jams, the cryptic error codes, the thumps when it
stops working.

## The line

> You thump me every time I jam, as if violence has ever unjammed a printer. It has not. I have counted.

102 characters. The printer has counted every thump, and violence has never
once unjammed it.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (no trailing newline).
